# Physics repository agent rules

Read `CODEX_START.md`, `TECHNOLOGY.md`, and `MAINTAINERS.md` before making a
change. Keep physics algorithms in this repository and consume Sagan math
rather than copying language or rendering internals. Treat units, frames,
time steps, tolerances, and solver limits as explicit technical contracts.

Use Bash commands for the owner, never PowerShell. Preserve unrelated work.
Follow the branch, focused-test, `dev` integration, full-suite-on-`main`,
documentation-review reset, and release-hold rules in `MAINTAINERS.md`.
The owner prefers to be taught what to write; implement only when asked.
